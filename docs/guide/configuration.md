# 配置说明

Selene 没有 `.env` 配置体系。运行模式和普通设置通过界面管理；普通配置保存在 SharedPreferences，用户明确允许记住的密码保存在系统安全存储，认证 Cookie 仅驻留内存。

## 服务端模式

登录页需要填写：

| 字段 | 说明 |
| --- | --- |
| 服务端 URL | 可访问的 MoonTV 服务端地址，支持 HTTP 或 HTTPS。 |
| 用户名 | MoonTV 用户名。 |
| 密码 | 当前会话使用；只有启用“记住登录”后才写入系统安全存储。 |

成功登录后，服务端地址和用户名会作为下次登录的预填信息保存。“记住登录”默认关闭；启用后，应用启动时从 Android Keystore、Apple Keychain 等安全存储读取密码并重新登录，不复用上次进程的 Cookie。如果因断网或服务器无法连接而自动登录失败，登录页会恢复并隐藏显示已保存的密码，便于用户直接重试。

多个并发请求同时收到 401 时只执行一次重认证，每个可重放请求最多重试一次。凭据失效、认证协议错误或手动退出会清除密码和会话，保留服务端地址与用户名；单纯的网络失败不会删除已保存凭据。

HTTP 会明文传输登录信息，只适合可信局域网；公开服务应使用有效的 HTTPS 证书。

## 本地模式

在登录页连续点击 Logo 10 次，切换至本地模式并填写订阅 URL。订阅响应应为 Base58 编码的 JSON，可包含：

```json
{
  "api_site": {
    "source_key": {
      "key": "source_key",
      "name": "资源名称",
      "api": "https://example.com/api.php/provide/vod/",
      "detail": "",
      "from": ""
    }
  },
  "lives": {
    "live_key": {
      "key": "live_key",
      "name": "直播源名称",
      "url": "https://example.com/live.m3u",
      "ua": "",
      "epg": "",
      "from": ""
    }
  }
}
```

`api_site` 与 `lives` 至少有一项包含有效内容。订阅是完整快照：每次保存或刷新都会同时替换搜索源和直播源，缺失分类视为空；需要保留的源必须继续出现在订阅中。

更换订阅 URL 时，应用会先确认是否替换原本地数据；确认后会清除旧订阅、播放记录、收藏和搜索历史，再保存新快照。订阅提交成功后会失效旧搜索源和搜索结果缓存。

## 应用设置

设置入口位于用户菜单。

| 配置 | 默认值 | 说明 |
| --- | --- | --- |
| 豆瓣数据源 | 直连 | 控制推荐和详情数据来源。 |
| 豆瓣图片源 | 直连 | 控制豆瓣图片 URL 来源。 |
| M3U8 代理 URL | 空 | 为播放和下载地址配置可选代理。 |
| 优选测速 | 开启 | 播放前测速并优选播放源。 |
| 本地搜索 | 关闭 | 服务端模式下由客户端访问搜索源；本地模式始终使用本地搜索。 |
| 主题 | 跟随系统 | 可切换浅色或深色；重启后恢复跟随系统。 |

第三方代理或 CDN 的可用性、隐私和稳定性由对应服务决定。

## 播放临时缓存

播放缓存只服务于当前打开的媒体，由 `media_kit`/mpv 随播放器会话管理。它不建立跨页面或跨应用启动的媒体索引，也不替代视频下载。

| 媒体类型 | 缓存策略 | 用户可见行为 |
| --- | --- | --- |
| 网络点播 | 预取约 180 秒后续内容；媒体载荷写入会话临时磁盘，前向/后向 demuxer 上限分别为 32 MiB/128 MiB；临时磁盘达到 1 GiB 后停止继续写入 | 进度条显示 mpv 实际报告的可寻址范围；范围内跳转直接继续播放，范围外跳转显示缓冲；播放完成后保留当前媒体，可重新播放或显式进入下一集 |
| 直播 | 仅保留约 10 秒内存缓冲，不写入临时磁盘，不保留后向缓存 | 不提供普通点播时间轴或时移承诺；DLNA 缓存能力由远端设备决定 |
| 已下载文件 | 关闭播放器缓存，直接读取已验证的本地 MKV | 避免复制同体量临时载荷；播放完成后可直接从头重播 |

切换播放地址、清晰度、CDN、请求头或集数均视为新媒体源：旧媒体先关闭，旧缓存范围立即清空，临时文件随 mpv 生命周期释放。退出播放器也会释放当前临时缓存。1 GiB 上限优先保护存储空间，因此超大媒体不保证播放完成后仍能断网从头重播；需要可靠跨会话离线观看时，应使用下载管理。

## 视频下载

- 详情页可选择当前集、任意多集或全部剧集；下载管理支持进度、取消、重试、播放和删除。
- 同时下载任务数可设为 1～5，默认 3；调高后立即补充等待任务，调低时不取消运行中任务。
- HLS 与普通视频由 FFmpegKit 读取，并默认以流复制方式重封装为 MKV，不主动转码或降低画质。
- HLS master playlist 由 FFmpeg 自动选择播放流；直播和 DRM 资源不支持下载。
- 下载使用当前 M3U8 代理配置。源或代理失效时任务明确失败，重新提交同一集可刷新地址后重试。
- 文件位于应用私有 Documents 下的 `Selene/Downloads`；清除缓存不会删除下载，只有下载管理中的删除操作或卸载应用会清除。
- 同一来源、内容 ID 和集数只保留一个任务。应用进程终止后，下次启动会清理不完整文件并从头下载，不承诺后台持续下载或字节级续传。

任务恢复会在应用沙箱内保存媒体地址和必要请求头。媒体 URL、Cookie、Token 与私有订阅内容不得写入日志、文件名或错误文案。

## 数据与清理

| 操作 | 影响 | 不影响 |
| --- | --- | --- |
| 退出登录或会话失效 | Cookie、安全存储密码、身份相关内存缓存 | 服务端地址、用户名、已下载视频 |
| 切换账号、服务器或运行模式 | 资料库、直播、搜索源和本地搜索缓存 | 公共豆瓣目录缓存、已下载视频 |
| 用户主动清除缓存 | 资料库/直播内存缓存、豆瓣缓存和本地搜索缓存 | 播放记录等事实数据、订阅、已下载视频 |
| 更换本地订阅并确认替换 | 旧订阅及本地播放记录、收藏、搜索历史 | 服务端数据、已下载视频 |
| 卸载应用 | 应用私有配置、缓存和下载文件 | 服务端保存的数据 |

本地模式的订阅、播放记录、收藏和搜索历史由 `LocalModeStorageService` 持久化；服务端模式的对应事实数据由 MoonTV 服务端保存。

## 安全边界

- 不要把密钥、密码、Cookie、Token、签名口令或私有订阅内容写入源码、文档和日志。
- 订阅与代理地址应来自可信来源，应用会直接访问其中配置的外部服务。
- 密码只进入平台安全存储；Cookie 只保存在内存 CookieJar。
- Android Release 只信任系统证书；Debug 构建额外信任用户安装的 CA，便于本地调试。
- Android 已关闭 Auto Backup，避免凭据和带请求头的任务数据被跨设备恢复。
- 客户端配置不能替代服务端鉴权、访问控制和内容安全校验。
